Help

  • Add commentsUse the comment tool, to the left of the pen: click a slide to comment on that spot, or drag to comment on an area. Write in the panel on the right and press “Add”. To comment on the whole slide, use “Add a comment on the whole slide” in the panel. The agent reads comments the same way it reads marks.
  • Draw, then tell the agent in chatDraw with the pen or highlighter, then send your instructions in the chat. The agent reads your marks and fixes the deck.
  • Add slidesIn the slide list below, hover between two slides to show “+”. Click it to put a blank new slide there. A new slide does not go into the PowerPoint file until the agent turns it into a real slide.
  • Reorder and deleteDrag slides in the list to reorder them. Hover over a slide and click “×” to delete it. Deleting happens right away, and the Undo button (Ctrl+Z) brings the slide back. Both change the PowerPoint file; the file as it was before is kept as a backup.
  • Start from a blank pageYou don’t need a PowerPoint file. Use “Open a deck” to start a blank sketchbook.

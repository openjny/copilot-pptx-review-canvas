# Contributing

Thanks for helping with Copilot PPTX Canvas. Bug reports, fixes, translations and ideas are all welcome.

## Prerequisites

- Windows 10 or 11 (the renderer drives desktop PowerPoint through COM).
- Node.js 22 or later. There are no runtime or development dependencies, so there is no `npm install` step.
- Desktop Microsoft PowerPoint, only for the smoke test and for screenshots. The unit tests use a fake renderer.
- Python with [uv](https://docs.astral.sh/uv/), only to regenerate the sample deck.

## Run the tests

```powershell
npm test
```

This runs every `*.test.mjs` file in [`com.github.copilot/extensions/pptx-slide-viewer/test/`](./com.github.copilot/extensions/pptx-slide-viewer/test). To check the real renderer against your PowerPoint:

```powershell
npm run smoke
```

## Where things live

[docs/architecture.md](./docs/architecture.md) describes the modules, the HTTP API and the data the extension keeps. The extension itself is in `com.github.copilot/extensions/pptx-slide-viewer/`; the plugin manifest is `plugin.json` at the repository root.

## Guidelines

- **No dependencies.** The extension uses Node built-ins and plain browser ES modules, with no build step. Please keep it that way.
- **Translate every visible string.** Text that a person or the agent reads goes into the catalogs, never inline: `lib/locales/en.mjs` and `lib/locales/ja.mjs` for the server, and `assets/locales/en.js` and `assets/locales/ja.js` for the browser UI. Both languages must have the same keys and placeholders; `test/i18n.test.mjs` and `test/ui-i18n.test.mjs` check this. Write the English first. If you cannot write Japanese, leave the Japanese entry as a best-effort translation and say so in the pull request. To propose another language, open an issue first.
- **Mind the page policy.** The page is served with `style-src 'self'`, so do not add `style=` attributes or inline `<style>` blocks. Use classes or the CSSOM.
- **Be careful with the `.pptx` file.** Reordering and deleting slides rewrite the file (`lib/pptx-zip.mjs`, `lib/pptx-reorder.mjs`, `lib/pptx-delete.mjs`). When you change them, add a test, run `npm run smoke`, and open a rewritten deck in PowerPoint to confirm that it opens without a repair prompt.
- **Keep paths short.** VS Code copies an installed plugin under a long prefix, and a copy fails on a PC where Windows long paths are disabled (260 characters). No path in the repository is longer than 80 characters; please stay under that.
- **Keep the sample deck neutral.** `samples/q3-review.pptx` is generated by `scripts/make_sample_deck.py`; change the script and regenerate rather than editing the file. Screenshots must show only this deck.

## Commits and pull requests

- Use [Conventional Commits](https://www.conventionalcommits.org/), for example `fix(reorder): keep sections when moving the first slide`.
- Describe the change, how you tested it, and your Windows and PowerPoint versions for anything that touches rendering or the file rewrite. Add a before and after screenshot for UI changes.
- Keep a pull request to one topic.

## Reporting a bug

Open an issue with the steps to reproduce, what you expected and what happened, your Windows and PowerPoint versions, and which Copilot client you use (VS Code, Copilot CLI or the Copilot app). The extension writes its logs to the session timeline, and its data is kept under `~/.copilot/extension-data/pptx-slide-viewer/`; please do not attach decks that contain confidential information.

For security problems, follow [SECURITY.md](./SECURITY.md) instead of opening a public issue.
